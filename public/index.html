WebTerm

Terminal SSH, SFTP, tunnel và terminal local trong một cửa sổ. Lấy cảm hứng từ MobaXterm.

Mở gần đây

Mẹo nhanh

  • Bôi đen để copy, chuột phải để dán (đổi được trong Cài đặt).
  • Bật nút ghim ở panel SFTP để panel đi theo thư mục hiện tại của terminal.
  • Chia để xem 2–4 terminal; MultiExec để gõ lên nhiều server một lúc.
  • Lưu lệnh hay dùng ở Macros, hoặc ghi lại thao tác gõ phím.
  • Kéo thả file hoặc cả thư mục vào SFTP để upload.
  • Phiên bị ngắt: bấm R trong terminal để kết nối lại.
  • Ctrl + K để tìm session, chuyển tab và mở công cụ; tìm được cả khi gõ không dấu.
  • Đóng nhầm tab? Bấm + → Mở lại tab vừa đóng, hoặc Ctrl + Shift + T trong app desktop.

Import session từ MobaXterm

Hoặc dán nội dung file MobaXterm.ini

Mật khẩu không được import vì MobaXterm mã hoá bằng master password. Lần đầu kết nối, WebTerm sẽ hỏi và có thể lưu lại.

Cài đặt

Giao diện ứng dụng

Chuột phải một file trong panel SFTP → "Sửa bằng app ngoài". Mỗi lần bạn lưu trong editor, WebTerm tự upload lại lên server.

SSH Tunnel

Local (-L): mở cổng trên máy này để vào dịch vụ trên server (vd. MySQL 3306). Remote (-R): mở cổng trên server để vào dịch vụ trên máy này. Dynamic (-D): proxy SOCKS5 đi qua server.
